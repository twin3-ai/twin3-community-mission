# Community Mission 題庫委員會初審

日期：2026-07-28  
範圍：General Knowledge 100 題、twin3 Learning Journey 100 筆、2026 年 3 月版 twin3 Whitepaper

## 結論

現有 200 筆題目只能作為候選素材，**不能直接進入正式 `$PoC` 場次**。

有效委員的主要意見高度一致：

- 題庫 A 與 B 有大量重複知識點。
- 正確選項通常最長，錯誤選項過於荒謬，容易不讀題猜中。
- 部分題目是行銷敘事，不是可驗證知識。
- 部分營運、經濟與排名資訊具有時效性。
- 至少一題與目前白皮書內容不一致。
- 多人場若讓先答完者立即看到答案，會破壞公平。

## 已確認問題

| 問題 | 例子 | 處理 |
|---|---|---|
| 編號衝突 | twin3 Journey 缺 Q69、Q72 重複 | 匯入前重新建立永久 ID |
| 白皮書不一致 | twin3 Journey Q55 的費用分配與白皮書不符 | 停用並重寫 |
| 概念重複 | 兩份題庫重複數位身分、Web2、資料主權、SBT 等概念 | 以知識點 ID 去重 |
| 答案長度洩漏 | 正確答案常是唯一長句 | 重寫四個長度相近的合理選項 |
| 行銷式題目 | twin3 Journey Q99-Q100 | 刪除或改為中立情境題 |
| 時效性內容 | SBT 數量、全球排名、合作與 Token 狀態 | 不作為永久題目 |
| 主題偏移 | 大量一般 Web2 與廣告追蹤題 | 只保留能支撐 Web3、Agent、Twin Matrix 的內容 |

## 初步處理比例

這是題庫層級估計，不是逐題最終裁定：

- **40-45% 可保留**：仍須來源與答案複核。
- **35-40% 必須重寫**：主要修正中立性、唯一正解、選項品質與來源。
- **約 20% 應刪除**：重複、偏題、行銷式或結構不合格。

## 500 題目標

| 主題 | 比例 | 題數 |
|---|---:|---:|
| Web3、資料主權與去中心化 | 30% | 150 |
| AI Agent、Personal Agent 與 Agentic Economy | 30% | 150 |
| Twin Matrix 白皮書與 twin3 協議 | 40% | 200 |

難度：

- 基礎理解 40%。
- 情境應用 40%。
- 進階判斷 20%。

## 題目與答案規則

正式題目必須：

1. 有且只有一個可由來源證明的答案。
2. 標註永久 ID、版本、知識點、來源章節與審核日期。
3. 使用中立文字，不把願景、價格、投資期待或品牌口號當成事實。
4. 四個選項長度、文法與可信度接近。
5. 至少經內容與技術兩位人類審核。
6. AI 只能協助草擬、去重與找風險，不能自行核准。

## 答案顯示

- 單人場：玩家送出後立即顯示正確答案與簡短說明。
- 多人場：所有玩家送出或倒數結束後，同步顯示正確答案。
- 每題完成答案揭示後才進入下一題。
- 完整解析與來源在全場結束後提供。

## 永不重複

- 題目第一次顯示即記為玩家已參與。
- 答對或答錯都不會再次出現。
- 每場 10 題；500 題最多提供 50 場。
- 完成所有正式題目後顯示 `Journey Complete`。
- 新題上架後才增加可參與場次。
- 作廢題目不列入完成上限。
- 參與紀錄以 `discord_uid + permanent_question_id` 建立唯一約束。
- 多裝置或重送請求必須原子取得同一場次，不得藉此換題。

## 獎勵邊界

- 同一玩家對每個永久題目最多取得一次 `$PoC`。
- 答錯後顯示答案，但不得重試或日後補領該題獎勵。
- 題庫內容可能被外部分享，因此單題獎勵維持低額，並設每日與每週上限。
- 任何結算都必須通過 Discord 身分、canonical identity 與 SBT eligibility。
